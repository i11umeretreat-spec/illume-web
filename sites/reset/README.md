# reset.i11ume.com

Страница практик восстановления: банная перезагрузка, глубокий йога-массаж,
дни-маршруты по острову.

Живёт в проекте Netlify `illumenew`, автодеплой из этого репозитория.
Рабочая копия: `public/reset/`. Эта папка — зеркало для истории изменений,
править нужно обе или копировать после правки.

DNS: CNAME `reset` → `illumenew.netlify.app`, Cloudflare, DNS only.

## История адресов

Раньше страница жила по адресу `royalmassage.i11ume.com` отдельным
проектом Netlify `nadimassage` с ручным деплоем перетаскиванием папки.
17.08.2026 переведена на автодеплой, 18.08.2026 переименована в `reset`.
Старый адрес отдаёт 301 на новый, чтобы разосланные ссылки не умерли.
Пока старый адрес нужен, запись CNAME `royalmassage` должна оставаться
в Cloudflare и домен должен числиться за проектом `illumenew`.

## Зависимости

Шрифты Fraunces, Space Grotesk и Inter подключаются с Google Fonts.
Локальных ресурсов нет, страница полностью текстовая.
