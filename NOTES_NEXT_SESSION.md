# i11ume — задачи для следующей сессии

## Дизайн-система: живость и тепло

### 1. Диагональные срезы между секциями
Направление одобрено (Tiers уже сделан как первая итерация).
Расширить на остальные секции лендинга по мере их появления.
Доработать: точная золотая линия-шов по диагонали (не приблизительный skew,
а точный расчёт угла через тот же clip-path что и у самой секции).
Референс: Sylvan (pin) — секции стыкуются по диагонали, не прямой линией.

### 2. Шрифты — сделать тоньше
Текущий Fraunces 600 в хиро ("Пока вы ведёте группу — мы заботимся о вас")
ощущается слишком тяжеловесно, "морковно" на цветном акценте (коралл C.p).
Пробовать: меньший font-weight (400-500 вместо 600), возможно светлее оттенок
коралла для текста именно этого размера, или другой способ акцента вообще
(не сплошная заливка текста цветом).

### 3. Убрать финальную точку в хиро-заголовке
"мы заботимся о вас." — точка ощущается слишком завершённой/тяжёлой.
Попробовать без точки, или другой финальный знак/приём.

### 4. Микро-анимация вместо статичного текста
Идея: лёгкая анимация "заботливых рук" рядом с фразой
"мы заботимся о вас" — визуализировать текст, не просто показать его.
Направление на подумать: SVG-анимация жеста (руки/ладони), либо
более абстрактная визуализация (мягкое свечение которое "обнимает" текст),
не буквальная иллюстрация рук чтобы не скатиться в клипарт.
Держать тон сдержанным — деталь, не спецэффект.

## Общий вектор
Референсы с Pinterest подтвердили направление: дуотон вместо честного
цвета фото, близкие/макро кадры, асимметричная сетка вместо одинаковых
карточек, serif+sans пара (уже есть — Fraunces+Space Grotesk), диагональные
разделители. Цель следующих итераций — довести эту теплоту и живость
до самого текста и типографики, не только до layout.
